================================================================================
  ExcelTool — Update the tablet catalog (Windows)
================================================================================

WHAT'S ON THE USB STICK
-----------------------
  ExcelTool.exe          the program
  adb\                   USB connection tools (keep together!)
  authorize_tablet.bat   technician runs once per tablet
  CUSTOMER_GUIDE_WINDOWS.txt   this file

WHAT YOU NEED
-------------
  • Windows PC
  • USB cable to the library tablet
  • Excel file (.xlsx) with the catalog columns (see README.md)

DAILY WORKFLOW
--------------
  1. Connect tablet by USB (File transfer / MTP if asked)
  2. Double-click ExcelTool.exe
  3. Step 1 — Import catalog (.xlsx)…  → pick your Excel file
  4. Review warnings in the table (fix sheet if needed)
  5. Step 2 — Send to tablet…
     → Confirm on the tablet when asked
     → The PC shows which file was sent (e.g. 3.xlsx)

  Only NEW books are added. Duplicates are skipped automatically.

TROUBLESHOOTING
---------------
  • "No tablet detected" — replug USB, run authorize_tablet.bat once
  • Keep ExcelTool.exe and the whole adb\ folder together
  • Tablet must show the confirm dialog — tap Add to finish
