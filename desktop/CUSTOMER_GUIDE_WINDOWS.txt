============================================================
  LibraryTool — Update the tablet catalog (Windows)
  AUTOMATIC — plug in USB, click one button
============================================================

WHAT'S ON THE USB STICK
  LibraryTool.exe          the program
  adb\adb.exe              talks to the tablet (do not delete)
  authorize_tablet.bat     technician — run once if PC not recognized
  CUSTOMER_GUIDE_WINDOWS.txt   this file

ONE-TIME SETUP (your technician — not the daily user)
  Each tablet must be provisioned as "device owner" once:
    adb shell dpm set-device-owner com.mh.librarymanager/.KioskDeviceAdminReceiver
  After that, USB debugging stays on automatically.

  Authorize the Windows PC (once per tablet):
    Option A — from Mac that already sees the tablet:
      authorize_from_mac.sh
    Option B — on Windows:
      Double-click authorize_tablet.bat (plug in tablet first)
    Option C — install Samsung/Android USB driver on Windows, then retry

------------------------------------------------------------
DAILY USE (3 clicks)
------------------------------------------------------------
  1. Plug tablet into PC with USB-C cable.
     (No menu to pick on the tablet — ignore "charge only" if it appears.)

  2. Double-click LibraryTool.exe
     → "1 · Import catalog (.xlsx)…"  → pick your Excel file
     → check the Review list (fix Excel if there are red errors)

  3. Click "2 · Send to tablet (automatic)…" → Yes
     → Wait until "Tablet updated" appears.
     → The screen shows which file was sent (e.g. 3.civ).
     → Unplug. Done.

The program sends the books and loads them on the tablet by itself.
Staff do NOT need to open files on the tablet for normal use.

IF importing manually on the tablet instead:
  The PC screen tells you the file number (e.g. "choose 3.civ").
  On the tablet: Management → Sync → pick that file from Download.

------------------------------------------------------------
IF IT SAYS "No tablet detected"
------------------------------------------------------------
  • Unplug and replug the USB cable
  • Try another USB port on the PC (not a cheap USB hub)
  • Install Samsung / Android USB driver on Windows
  • Keep LibraryTool.exe and the whole adb\ folder together
  • Technician: run authorize_tablet.bat once

IF IT SAYS "not authorized"
------------------------------------------------------------
  The tablet was set up from a different computer.
  Technician runs authorize_tablet.bat or authorize_from_mac.sh once.
  Daily staff do not touch the tablet.

------------------------------------------------------------
EXCEL FORMAT
------------------------------------------------------------
  First row = headers: שם הספר, המחבר, מספר, אות, צבע, קטגוריה,
  תת קטגוריה, ענינים, הערות
  (English names like name, author, number also work.)
